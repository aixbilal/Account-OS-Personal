# Theme System

**LOCKED:** user-facing modes are Hybrid (signature/default), Dark, Light, and System. System follows OS Light/Dark, not Hybrid.

Hybrid combines graphite/dark app chrome with soft lighter work surfaces and restrained security/service accents. Dark-dominant areas are navigation, app chrome, Unlock, Map, command/search overlays, and suitable security-critical overlays. Softer areas are Vault list/inspector, forms, Settings, Devices, and Backup/Recovery. Dialogs, account details, search results, and Security may be mixed intentionally.

Dark and Light preserve the same hierarchy. Hybrid is not random black-and-white panels. Lock roles and token structure, not final hex values: background, chrome, work surface, elevated surface, text primary/secondary, border, focus, selection, success/warning/danger, security state, service accent, and map surface. Final color tuning is implementation-tested with contrast and theme review.
