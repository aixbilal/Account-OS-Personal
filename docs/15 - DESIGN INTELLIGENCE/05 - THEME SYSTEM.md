# Theme System

## Direction

**LOCKED:** Future planning supports Hybrid, Dark, Light, and System behavior where technically appropriate. WCAG-conscious contrast, visible focus, reduced motion, and non-color-only security meaning are required.

**PROVISIONAL:** Hybrid is the signature/default candidate: graphite chrome; lighter/frost work surfaces; restrained service/security accents. Dark may suit navigation, Map, security overlays, and unlock; lighter surfaces may suit Vault, inspector, forms, settings, devices, and backup management. Final colors require visual audit.

## Existing proven tokens (do not redefine here)

`--surface-0 #090b0f`, `--surface-1 #0f1218`, `--surface-2 #151922`, `--surface-3 #1b202b`, `--line #252b37`, `--line-strong #323a49`, `--text #e7eaf0`, `--text-muted #adb7c8`, `--text-faint #8b97aa`, `--accent #7f9cf5`, `--accent-soft rgba(127,156,245,.12)`, `--success #71c49a`.

Future semantic coverage: background, surface/elevated surface, primary/secondary text, border, focus, success/warning/danger, security, selection, service accent, and map surface across all modes. Unresolved values remain provisional in `design/theme-tokens.json`.
