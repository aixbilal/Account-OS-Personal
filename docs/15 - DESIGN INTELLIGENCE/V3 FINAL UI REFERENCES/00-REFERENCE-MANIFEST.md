## Implementation rule

Match the approved composition, spacing, hierarchy, palette and overall visual character as closely as practical.

Do not invent unsupported functionality merely because a generated reference contains it.

Preserve existing Account OS:
- encryption
- vault architecture
- relationships model
- backup / restore
- sync architecture
- security behavior
- local-first privacy model

The approved direction is a calm, premium, light Account OS interface with restrained blue accents and service-aware identity where appropriate.
